# Contributing to Callio

Thanks for helping! A few notes:

- Build and run: see *Building from source* in the README. `npm run dev` runs the interface in a browser with a mock backend, which is the quickest way to work on the UI.
- Keep it light: no Python, no new heavy runtimes; office formats go through `office/` (the Craft engines).
- Never overwrite a user's file without a backup, and keep AI edits reviewable and undoable.
- Secrets belong in Windows Credential Manager, never in settings files or logs.

By contributing you agree that your contribution is dual-licensed under MIT OR Apache-2.0, like the rest of Callio.
