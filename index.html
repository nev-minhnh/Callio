              Git integration (official)
              
Create a token in Overleaf → Account Settings → Git integration. Stored in Windows Credential Manager. Requires Git for Windows.

              
            

            

              Overleaf account (project list, web sync, Overleaf compiles)
              
Sign in once in Callio's Overleaf window (email, Google, ORCID or your institution). Callio keeps the session fresh by itself and renews it automatically when it expires.

              

                
                
                
              

              
              
Advanced: paste a session cookie manually
                
Only if the sign-in window can't be used: copy overleaf_session2 from your browser's DevTools → Application → Cookies.

Callio 
Shape your folio

            
A lightweight editor for Markdown, LaTeX, Word documents, spreadsheets, presentations, PDF and pictures. Built with Rust (Tauri), CodeMirror, KaTeX, PDF.js and Callio's own engines for documents, spreadsheets, presentations, PDF and pictures.

            
Open source under the MIT or Apache-2.0 licence · github.com/nev-minhnh/Callio

Uninstall

            
Removes Callio completely: “Open with” and default-app entries, saved keys and sign-ins, settings, AI memory, history, the paper library, the TinyTeX it installed, skills it copied to Claude Code, and the program itself. Your own documents are never touched.
